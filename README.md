# MyProject

### Software Engineering | AI Systems & Performance Optimization

Exploring the intersection of **AI inference, computer architecture, and high-performance computing**.

My primary focus is understanding how software interacts with hardware, identifying performance bottlenecks through profiling and benchmarking, and developing practical optimization strategies.

## Core Projects

### Vision_QC — Industrial Computer Vision
**Tech:** Python · PyTorch · OpenCV · Ultralytics YOLO11

An industrial visual inspection project focused on object detection, defect identification, and inference performance evaluation.

- Build and evaluate YOLO11-based inspection pipelines.
- Explore preprocessing, model deployment, and inference optimization.
- Analyze latency, throughput, memory usage, and detection accuracy.
- Investigate hardware-specific performance bottlenecks.

**Goal:** Develop a reproducible workflow from computer vision prototyping to practical industrial deployment.

### Project APEX — CPU Characterization & Digital Twin
**Tech:** C++ · Python · AMD Ryzen · Performance Profiling

An experimental research project investigating CPU voltage-frequency behavior, dynamic boosting, and silicon characteristics.

- Characterize per-core voltage-frequency relationships.
- Investigate AMD Precision Boost Overdrive and Curve Shaper behavior.
- Analyze workload-dependent stability and performance.
- Develop per-sample CPU digital twins and reproducible silicon performance fingerprints.

**Goal:** Establish a measurement-driven framework for CPU characterization and overclocking optimization.

### Smart_Aero — Fast Aerodynamic Approximation
**Tech:** C++ · Numerical Computing · SIMD Optimization

A performance-oriented project exploring fast approximate aerodynamic calculations for real-time applications and gaming environments.

- Investigate computationally efficient aerodynamic approximations.
- Optimize numerical workloads and memory access patterns.
- Explore SIMD acceleration and CPU performance scaling.
- Evaluate the trade-offs between computational accuracy and execution time.

**Goal:** Achieve practical real-time performance through algorithmic and hardware-aware optimization.

## Research Interests

- **AI Systems:** Model deployment, inference acceleration, and cross-platform adaptation.
- **Computer Architecture:** CPU microarchitecture, cache hierarchy, memory latency, and scheduling.
- **Performance Engineering:** Profiling, benchmarking, SIMD, and bottleneck analysis.
- **Hardware Characterization:** Voltage-frequency modeling, dynamic boost behavior, and stability analysis.

## Engineering Approach

**Build → Measure → Analyze → Optimize → Validate**

I believe meaningful performance improvements begin with reproducible measurements and a clear understanding of system behavior.

My goal is to bridge the gap between high-level software frameworks and low-level hardware execution.
